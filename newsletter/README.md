# 다꾸 채널 소식(뉴스레터) 초안

매일 새 체험단 등록이 끝난 뒤 자동으로 만들어지는 카카오톡 채널 메시지 초안이에요.
시온님이 복사해서 카카오톡 채널 관리자센터(메시지 작성)에서 직접 보내요. Claude 는 채널에 직접 발송하지 않아요.

작성 규칙 (뉴스레터 톤, 카카오톡은 첫 두 줄이 제일 중요)
- 첫 두 줄 = 훅. 짧고 세게, 이모지 1~2개. 그날 데이터에서 가장 센 사실 하나로 고른다. 패턴 예:
  · 마감임박! 오늘 신청하세요 ⏰ (오늘 마감인 것이 있을 때)
  · 오늘 오픈! N만원 상당 ○○가 체험단에 떴어요 💸 (worth 가 있을 때만 금액을 쓴다)
  · 오늘 신규 체험단 N곳 OPEN! 🎉 (그날 새로 올라온 개수)
  · 숙박비 걱정이라면 주목! 풀빌라 체험단 N곳 🏊 / 우리 아이 육아템, 무료로 써볼 기회 👶 / 매일 아침 특가 소식 🔥
- 3줄 이후: 픽 3개(이모지 + [숙박]/[육아] + 이름 + 한 줄 혜택 + 마감) → "🔥 오늘의 특가" 두 줄(특가 탭 맨 위 "🏆 지금 할인율 TOP" 에 나오는 상품 중에서만 고른다 — app.js topDeals(4) 와 같은 규칙: toss(품절 제외)·babyDeals·goldbox 를 할인율 순으로 4개, 아기용품 1등은 꼭 포함. 상품 짧은 이름 + 할인율↓ + 가격 + 끝나는 시각: 쿠팡 골드박스·아기용품은 "내일 7시까지", 토스는 "밤 12시까지", 품절 제외) → 마무리 한 줄.
- 사실만. 금액·개수·마감은 data.json 그대로. "당첨률 높은", "인기 많은", "80만원대" 같은 말은 데이터 근거(worth, 다꾸 추천 pick)가 있을 때만 쓴다. 이름(OOO님) 개인화는 채널 메시지에서 안 되므로 쓰지 않는다.
- 본문에는 링크(URL)를 넣지 않는다. 링크는 맨 밑 버튼 2개로만: "버튼1: 이름 | 주소", "버튼2: 이름 | 주소".
  기본 버튼1 "오늘 오픈 체험단 보기 | https://dagguu.github.io/#/list?cat=stay&s=open", 버튼2 "오늘의 특가 보기 | https://dagguu.github.io/#/deals".
- 본문은 반드시 300자 이내(공백·줄바꿈 포함, 버튼 제외). 넘으면 픽을 줄인다. 맨 위에 "훅 후보" 2개를 따로 더 적어 시온님이 골라 쓸 수 있게 한다.

캐러셀형(피드형) 카드 메시지 (2026-10-15 추가, 웅진마켓·마이리틀타이거 채널 같은 형식)
- 카카오 규격: 카드 2~6장, 이미지 비율 2:1~3:4(우리는 900x1200, 3:4), jpg 5MB 이하. 카드마다 제목 20자, 설명 180자(줄바꿈 2번까지), 버튼 1~2개(버튼 이름 8자). "(광고)" 표시는 카카오가 붙인다.
- 카드 6장 기본: 숙박 2 + 육아 2 + 특가 2(아기용품 핫딜 1등 + 토스·골드박스 할인율 1등). 체험단은 위 텍스트형과 같은 기준으로 고른다.
- 숙박 카드 고르기(2026-10-15 시온님 요청): 누가 봐도 가고 싶은 곳, 사진 풍경이 멋진 곳만. 모텔 같은 도심 숙소(역·터미널·시내 호텔, "by 아늑", 대실, 랜덤 객실 비즈니스호텔 등)와 사진이 침대·복도·건물 간판뿐인 곳은 쓰지 않는다. 풀빌라·리조트·오션/마운틴뷰·한옥·독채·글램핑처럼 풍경·수영장·야경이 사진에 보이는 곳 우선.
  · 사진은 작업 컨테이너에서 직접 못 보므로, 먼저 오늘 숙박 후보 전부를 date "pick-YYYY-MM-DD" 로 kakao_queue.json 에 넣어 push → Actions 가 만든 insta 브랜치 kakao/pick-YYYY-MM-DD/N.jpg 를 git show 로 받아 직접 보고 2곳을 고른다. 그다음 진짜 queue 로 다시 push.
  · 오늘 올라온 숙박 중 그런 곳이 2곳이 안 되면 어제 올라온(createdAt) 모집중 숙박에서 사진이 멋진 곳으로 채우고, 그 카드는 pill 을 "인기 숙박 체험단"으로, 제목을 "[인기 숙박] 숙소 지역"으로 소개한다(시온님 요청). 금액이 큰 것(worth)·사이트 추천(pick) 우선.
- scripts/kakao_queue.json = {"date", "cards":[{img, fit(숙소 cover / 제품 contain), bg(파스텔), accent, pill, l1, l2, sticker, title, desc, btn, url}]} 을 push 하면 Actions(kakao.yml)가 scripts/gen_kakao.py 로 카드 이미지를 만들어 insta 브랜치 kakao/<날짜>/1~6.jpg 에 올린다.
  · 이미지 글씨: pill(예 "목포 숙박 체험단"·"육아 체험단"·"쿠팡 골드박스 핫딜"·"토스 하루특가"), l1(숙소·제품 짧은 이름), l2(혜택 한 마디: "전액 페이백"·"1박 숙박권"·"19,300원"), sticker(짧게: "48%\n할인", "46,200원\n페이백", "~10/22\n모집").
  · 카드 글: 제목 "[숙박] 숙소 지역" / "[육아] 브랜드 제품" / "[핫딜🔥] 상품" / "[하루특가] 상품". 설명 3줄 = 혜택 원문 + 매체·구매평 + "✔기간 : ~M/D"(특가는 원가→가격(할인율↓) + "✔내일 아침 7시까지"/"✔오늘 밤 12시까지").
  · 버튼: 체험단 "신청하러가기 | https://dagguu.github.io/s/{id}.html", 특가 "특가 보러가기 | https://dagguu.github.io/#/deals".
  · 사실만(data.json 그대로), "인기" 같은 근거 없는 말 금지. 원문에 없는 위치·시설 설명을 지어내지 않는다.
- python3 scripts/gen_kakao.py --text 로 글자수를 검사하고 카드별 이미지 주소·제목·설명·버튼을 뽑아 newsletter/YYYY-MM-DD-carousel.txt 로 저장한다.
