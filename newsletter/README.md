# 다꾸 채널 소식(뉴스레터) 초안

매일 새 체험단 등록이 끝난 뒤 자동으로 만들어지는 카카오톡 채널 메시지 초안이에요.
시온님이 복사해서 카카오톡 채널 관리자센터(메시지 작성)에서 직접 보내요. Claude 는 채널에 직접 발송하지 않아요.

작성 규칙
- 그날 새로 올라온(createdAt 오늘) 모집 중 체험단 중 3~5개만 고른다.
  고르는 순서: worth("N만원 상당")가 있는 것 → 키즈·풀빌라·아이 동반 숙소 → 아기 나이가 명시된 육아 → 마감이 가까운 것. 숙박과 육아를 섞는다.
- 사실만 쓴다. "인기 많은", "후기 좋은" 같은 말은 데이터 근거(다꾸 추천 pick 등)가 있을 때만. 혜택·금액·마감일은 data.json 그대로.
- 형식: [숙박]/[육아] 머리표, 숙소·제품 이름(지역), 혜택 한 줄, 마감일, 바로가기 링크 https://dagguu.github.io/s/{id}.html
- 전체 400자 안팎, 이모지는 줄마다 1개 정도. 끝에 사이트 링크와 "광고 표시"는 채널 메시지 규칙에 따라 시온님이 발송 화면에서 선택.
