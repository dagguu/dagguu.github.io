# 다꾸 채널 소식(뉴스레터) 초안

매일 오후 2:37, 그날 업데이트(특가·체험단 등록)가 다 끝난 뒤 자동으로 만들어지는 카카오톡 채널 메시지 초안이에요.
시온님이 복사해서 카카오톡 채널 관리자센터(메시지 작성)에서 직접 보내요. Claude 는 채널에 직접 발송하지 않아요.

작성 규칙 (뉴스레터 톤, 카카오톡은 첫 두 줄이 제일 중요)
- 첫 두 줄 = 훅. 짧고 세게, 이모지 1~2개. 그날 데이터에서 가장 센 사실 하나로 고른다. 패턴 예:
  · 마감임박! 오늘 신청하세요 ⏰ (오늘 마감인 것이 있을 때)
  · 오늘 오픈! N만원 상당 ○○가 체험단에 떴어요 💸 (worth 가 있을 때만 금액을 쓴다)
  · 오늘 신규 체험단 N곳 OPEN! 🎉 (그날 새로 올라온 개수)
  · 숙박비 걱정이라면 주목! 풀빌라 체험단 N곳 🏊 / 우리 아이 육아템, 무료로 써볼 기회 👶 / 매일 아침 특가 소식 🔥
- 3줄 이후: 픽 3개(이모지 + [숙박]/[육아] + 이름 + 한 줄 혜택 + 마감) → "🔥 오늘의 특가" 두 줄(특가 탭 맨 위 "🏆 지금 할인율 TOP" 에 나오는 상품 중에서만 고른다 — app.js topDeals(4) 와 같은 규칙: toss(품절 제외)·babyDeals·goldbox 를 할인율 순으로 4개, 아기용품 1등은 꼭 포함. 상품 짧은 이름 + 할인율↓ + 가격 + 끝나는 시각: 쿠팡 골드박스·아기용품은 "내일 7시까지", 토스는 "밤 12시까지", 품절 제외) → 마무리 한 줄.
- 사실만. 금액·개수·마감은 data.json 그대로. "당첨률 높은", "인기 많은", "80만원대" 같은 말은 데이터 근거(worth, 다꾸 추천 pick)가 있을 때만 쓴다. 이름(OOO님) 개인화는 채널 메시지에서 안 되므로 쓰지 않는다.
- 본문에는 링크(URL)를 넣지 않는다. 링크는 맨 밑 버튼 2개로만: "버튼1: 이름 | 주소", "버튼2: 이름 | 주소".
  기본 버튼1 "새 체험단 보기 | https://www.dagguu.com/#/list?cat=stay&s=open", 버튼2 "오늘의 특가 보기 | https://www.dagguu.com/#/deals".
- 본문은 반드시 300자 이내(공백·줄바꿈 포함, 버튼 제외). 넘으면 픽을 줄인다. 맨 위에 "훅 후보" 2개를 따로 더 적어 시온님이 골라 쓸 수 있게 한다.

캐러셀형(피드형) 카드 메시지 — 글 + 카드 이미지 (2026-10-16 시온님 요청: Claude 가 v2 스타일 이미지를 만든다. 예시 newsletter/2026-10-16-carousel.txt·scripts/kakao_queue.json)
- 카카오 규격: 카드 2~6장, 카드마다 제목 20자(줄바꿈 없음), 설명 180자(줄바꿈 2번까지), 버튼 1~2개(버튼 이름 8자).
- 카드 1장 = 주제 1개에 체험단·특가 4개 모음(2026-10-16 시온님 요청: 이미지는 시온님이 GPT 로 만듦, 예시는 "전액 페이백 육아템 체험단" 2x2 카드 이미지). 4~6장, 주제 예: 오늘 마감 체험단, 내일 마감 숙박, 오늘 오픈/새로 올라온 감성 숙소(풍경 좋은 곳, 모텔 같은 도심 숙소 제외), 인기 풀빌라, 전액 페이백 육아템, 쿠팡 골드박스 아기용품 핫딜, 토스 하루특가. 금액 큰 것·할인율 큰 것 우선.
- 아기용품·페이백만 몰지 않기(2026-10-19 시온님 요청, 2026-10-20 발송분부터):
  · 핫딜·특가는 아기용품만 넣지 말고 생활용품(휴지·세제·주방·청소·생수 등, data.json goldbox·moreDeals·toss 중 endAt 이 지금 이후인 것)을 섞는다. 핫딜 카드 4개는 아기용품 2 + 생활용품 2 정도로(제목·라벨도 "아기·생활 핫딜"처럼). 체험단 카드도 육아만이 아니라 생활(cat:"life") 체험단을 섞는다.
  · 페이백 카드만 넣지 말고 "입장권·티켓 왔어요" 카드를 1장 넣는다: 먼저 티켓 체험단(data.json items cat:"etc" — 테마파크·아쿠아리움·뮤지엄 입장권, end ≥ 오늘) 중 새로 올라온 것·금액 큰 것·마감 가까운 것 4개(지역이 겹치지 않게). 4개가 안 되면 data.json seasonDeals 의 입장권 상품(promo.items 키: "아쿠아리움 입장권"·"롯데월드 입장권"·"에버랜드 이용권"·"입장권", 이름의 이용 기간이 지난 것은 뺌)으로 채우되, 할인율 데이터가 없으니 가격만 쓴다("%"·"최저가" 금지). 꼬리표 [나들이🎡](새로 올라온 게 대부분이면 [NEW✨]), 버튼 "티켓 보러가기 | https://www.dagguu.com/#/list?cat=etc" (특가 상품만이면 #/deals). 예 제목: "[나들이🎡] 제주 입장권 왔어요". 색은 다른 카드와 겹치지 않게.
  · 페이백 카드는 그날 고가 페이백이 있을 때만(없으면 빼도 됨). 텍스트형 "🔥 오늘의 특가" 두 줄도 아기 1 + 생활 1 로.
- 카드 이미지 스타일은 2026-10-21부터 v4(시온님이 보여준 @moeumi_log "5분만에 알고리즘 선택 받는 카드뉴스 만드는 법" 카드처럼): 사진 한 장을 꽉 채우고(2026-10-22 시온님 요청으로 사진은 밝게 두고 아래 글씨 자리만 어둡게 그라데이션), 왼쪽 아래에 굵은 흰 글씨(프리텐다드) 2~3줄 + 그 아래 작은 설명 한 줄, 오른쪽 위 작은 www.dagguu.com. 스티커·색종이·타일·그라데이션 색 없음. 카드마다 "style":"v4", h(큰 글씨 줄 배열, 2~3줄, 줄당 10자 안팎 — 길면 글씨가 작아짐), sub(설명 한 줄, 20자 안팎), bgimg(배경 사진 1장: 숙소는 외관·객실처럼 분위기 있는 컷, 글씨 많은 홍보 이미지는 피함), fit(숙소 cover / 제품 contain — contain 이면 흐린 배경 위 가운데에 제품 사진. 입장권처럼 홍보 글씨가 많은 사진도 contain 으로 넣어 큰 글씨와 겹치지 않게). 4개 모음 내용은 글씨(h·sub)와 카카오 설명(desc)에 담는다. tiles 는 남겨 둬도 이미지에는 안 쓴다.
- (옛) 2026-10-17~10-20 v3(화려한 스타일, 시온님 요청 "칙칙해, 화려하게"): 카드마다 "style":"v3", accent·accent2(쨍한 그라데이션 두 색, 예: 핑크 #ff2e88→주황 #ff8a3d, 빨강 #ff3131→#ff9f1c, 파랑 #2f6bff→#00c2ff, 초록 #00a862→#00c9b7, 보라 #7b2ff7→#ff2e9a). 햇살 무늬·색종이 배경, 흰/노랑 외곽선 제목, 노란 별 스티커, 타일 번호 배지, 노란 가격표·버튼이 자동으로 들어간다. light·bg 는 v3 에서 안 쓴다. 나머지 필드(label·l1·l2·sub·sticker·cta·tiles)는 v2 와 같다. 카드끼리 색이 겹치지 않게 고른다.
- (옛) 카드 이미지(v2, 시온님이 보여준 "전액 페이백 육아템 체험단" 예시 스타일): scripts/kakao_queue.json 의 각 카드에 "style":"v2", accent(메인 컬러), light(연한 색), bg, label(맨 위 둥근 라벨), l1·l2(큰 제목 두 줄, 각 6자 안팎), sub(제목 아래 한 줄), sticker(물결 스티커 2~3줄), cta(맨 아래 버튼 문구), tiles 4개 {img, fit(숙소 cover/제품 contain), name(10자 안팎), copy(짧은 문구 2줄, 상품명·제공내역에 있는 말로만), price(가격 버튼: "46,200원 환급"·"50만원 상당"·"▼55% 18,000원")} 와 title·desc·btn·url 을 넣어 push → Actions(kakao.yml)가 insta 브랜치 kakao/YYYY-MM-DD/N.jpg 를 만든다(3~4분). git show 로 받아 직접 보고 글씨 넘침·깨진 사진은 고쳐 다시 push.
- 배경 사진 화질(2026-10-23 시온님 "사진 화질 안좋으면 다른 사진을 써줘"): 카드 배경(bgimg)은 원본 가로·세로가 모두 1000px 안팎 이상인 사진만 쓴다(카드 900x1200 을 꽉 채우므로 작은 사진은 흐려짐). gen_kakao.py 가 카드마다 실제 크기를 insta 브랜치 kakao/<날짜>/probe.txt 에 남기니(작업 컨테이너는 쿠팡 사진 서버에 못 닿음) 이미지를 확인할 때 같이 보고, 작은 것(예: 657x313)은 다른 사진으로 바꾼다. 후보 사진 크기를 미리 보려면 kakao_queue.json 에 "probe":[주소…] 를 넣고 push → probe.txt 에 같이 나옴(확인 뒤 probe 는 지움).
- 제품·입장권 카드 배경(2026-10-23 시온님 "배경으로 사진을 꽉 채워"): 제품·입장권 카드도 fit cover 로 사진을 꽉 채운다. 흰 바탕 누끼컷보다 생활 연출 사진(예: 수납함이 놓인 방)을 고르고, 글씨가 많은 홍보 포스터·사람 얼굴이 보이는 사진은 피한다. 사진과 카드 글씨(h)가 맞게(사진 속 상품이 글씨에 나오게) 쓴다.
- python3 scripts/gen_kakao.py --text 로 글자수 검사 후 그 출력(카드별 이미지 주소·제목·설명·버튼)을 newsletter/YYYY-MM-DD-carousel.txt 로 저장한다.
- 제목: "[꼬리표+이모지] 주제" (예: "[전액페이백💸] 육아템 체험단", "[오늘종료⏰] 오늘 마감 체험단") — 꼬리표는 [오늘오픈🎉] [오늘종료⏰] [내일종료⏰] [NEW✨] [전액페이백💸] [인기🔥] [핫딜🔥] [하루특가⚡] 중. [오늘오픈🎉]은 모집 시작일(start)이나 등록일(createdAt)이 보내는 날(오늘)인 체험단에만 쓰고, 어제 올라온 것은 [NEW✨]로 쓴다(2026-10-16 시온님 요청). 오늘 오픈이 있으면 카드 1~2장에 꼭 넣는다. 
- 제목 뒷부분은 클릭하고 싶은 한마디로 쓴다(2026-10-18 시온님 요청: "매일 똑같아서 클릭하고 싶지 않다", 2026-10-19 발송분부터). [꼬리표+이모지]는 그대로 두고, 그 옆 "오늘 마감 체험단"·"육아템 체험단" 같은 주제 이름 대신 말 거는 듯한 훅을 쓴다. 시온님 예시: "[오늘종료⏰] 70만원 숙소가 떴어요"(21자라 느낌표는 뺌).
  · 20자 안(꼬리표 포함, gen_kakao.py 가 검사). 카드끼리, 그리고 전날 newsletter/*-carousel.txt 제목과 같은 문장을 반복하지 않는다(매일 표현을 바꾼다).
  · 그날 카드 안의 가장 센 사실 하나를 훅으로: 금액("70만원 숙소가 떴어요"), 지역("제주 바다 앞 숙소 왔어요"), 시설("수영장 딸린 독채가 떴어요"), 마감("내일이면 못 가요ㅠ"), 할인율("38% 내린 육아템"), 대상("아이랑 갈 숙소 찾았어요").
  · 사실만 세게(2026-10-22 쿠팡 파트너스 공지 "허위·과장·오인 표현으로 클릭 유도 금지"): 금액·지역·시설·마감일·할인율처럼 data.json 에 있는 사실로 훅을 만든다. "역대급·미쳤다·가격 오류·최저가·제일 싸요·오늘만·마지막 기회·서두르세요·빨리·지금 달려·담아·안 사면 후회·품절되기 전·다들 신청했대요·당첨 보장·공짜" 같은 말은 쓰지 않는다(체험단 카드도 같은 글에 쿠팡 특가가 같이 나가므로). 할인율·가격은 그날 data.json 값만, 일부 회원 전용 가격(와우·카드 할인)은 일반 가격처럼 쓰지 않는다.

- 설명 3줄, 줄마다 끝에 이모지 1개(2026-10-16 시온님 요청). 시온님 예시:
