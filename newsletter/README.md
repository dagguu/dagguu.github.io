# 다꾸 채널 소식(뉴스레터) 초안

매일 새 체험단 등록이 끝난 뒤 자동으로 만들어지는 카카오톡 채널 메시지 초안이에요.
시온님이 복사해서 카카오톡 채널 관리자센터(메시지 작성)에서 직접 보내요. Claude 는 채널에 직접 발송하지 않아요.

작성 규칙 (뉴스레터 톤, 카카오톡은 첫 두 줄이 제일 중요)
- 예약 발송(2026-10-15 시온님 요청): 초안은 저녁 6시에 오고, 시온님이 밤에 예약해 두면 다음 날 보내질 수 있다. 그래서 "오늘"·"오늘 신규/오픈"·"N곳 OPEN" 처럼 보내는 날이 바뀌면 틀리는 말은 쓰지 않는다.
- 첫 두 줄 = 훅. 짧고 세게, 이모지 1~2개. 그날 고른 픽에서 가장 센 사실 하나로, 매일 다른 패턴을 돌려 쓴다(전날 newsletter 파일과 겹치지 않게). 패턴 예:
  · 전액 페이백 육아템, 놓치기 아까워요 💸 (pay 에 payback 이 있을 때)
  · N만원 상당 ○○, 체험단으로 받아보세요 🎁 (worth 가 있을 때만 금액)
  · 스위트룸 1박, 체험단으로 가볼까요? 🏨 / 이번 주말엔 풀빌라 어때요? 🏊 (benefit 에 실제로 있는 말만)
  · 마감 전에 꼭 신청하세요 ⏰ (마감이 1~2일 남은 것이 있을 때, 날짜는 M/D 로)
  · 다꾸가 골라온 체험단 PICK 💜 / 우리 아이 육아템, 써보고 리뷰하기 👶
  "인기"·"인기 많은"·"당첨률 높은" 은 신청자 수 데이터가 없으니 쓰지 않는다(사이트 인기순은 자체 점수라 근거가 아님).
- 픽은 마감이 2일 이상 남은 것을 고른다(다음 날 보내면 당일 마감이 되므로).
- 3줄 이후: 픽 3개(이모지 + [숙박]/[육아] + 이름 + 한 줄 혜택 + 마감) → 특가 한 줄(가격·할인율·끝나는 시각은 쓰지 않는다. 골드박스는 아침 7시, 토스는 밤 12시에 바뀌어서 예약 발송 때 틀린다. 예: "🔥 매일 아침 바뀌는 쿠팡·토스 특가도 버튼에서 확인하세요", "🍼 아기용품 특가는 매일 아침 7시에 새로 바뀌어요") → 마무리 한 줄.
- 사실만. 금액·개수·마감은 data.json 그대로. "당첨률 높은", "인기 많은", "80만원대" 같은 말은 데이터 근거(worth, 다꾸 추천 pick)가 있을 때만 쓴다. 이름(OOO님) 개인화는 채널 메시지에서 안 되므로 쓰지 않는다.
- 본문에는 링크(URL)를 넣지 않는다. 링크는 맨 밑 버튼 2개로만: "버튼1: 이름 | 주소", "버튼2: 이름 | 주소".
  기본 버튼1 "체험단 모아보기 | https://dagguu.github.io/#/list?cat=stay&s=open", 버튼2 "특가 모아보기 | https://dagguu.github.io/#/deals".
- 본문은 반드시 300자 이내(공백·줄바꿈 포함, 버튼 제외). 넘으면 픽을 줄인다. 맨 위에 "훅 후보" 2개를 따로 더 적어 시온님이 골라 쓸 수 있게 한다.
