# 인스타 @dagguu.trip 영상 피드 (2026-10-29 시온님)

숙찾남(roomfinder.kr) 피드처럼 한 게시물 = 5장, 장마다 4초 영상. 첫 장만 시온님 원래 표지 글씨(해시태그 한 줄 + 흰 글씨 1줄 + 노란/하늘색 1줄 + 오른쪽 위 @dagguu.trip), 2~5장은 영상 + @dagguu.trip 만.

## 만드는 순서 (매일 19:44 예약 작업)
1. 숙소 = 그날 감성숙소 매거진 숙소(scripts/stays/<slug>.json). 같은 숙소 릴스 장면 영상(insta 브랜치 video/<날짜>/<slug>/clip_ai*.mp4)이 있으면 그걸 고르고 새로 만들지 않는다(크레딧 0).
2. 없으면 scripts/kie_prompts/<slug>.json 에 장면 5개 img 프롬프트(사진을 9:16 으로 늘리기, 사물·건물 그대로, 사람은 많아야 1장·한국인 뒷모습/옆모습·흰 긴 치마) → kie-image.yml(slug, only=번호) → scripts/carousel/<slug>.json → kie-scenes.yml(name=<slug>, src=scripts/carousel/<slug>.json). 약 200크레딧(이미지 4 + 영상 35, ×5).
3. carousel.yml(slug) → insta 브랜치 carousel/<slug>/1~5.mp4, 1_notext.mp4(글씨 없는 첫 장), cover.jpg + 메일.

## 장면 5개 고르기 (숙찾남 순서 참고)
1장 = 그 숙소 대표 시설(노천탕·객실 수영장·스파 등, 표지 글씨가 말하는 바로 그 장면) → 2장 다른 물·뷰 시설 → 3장 사람 있는 분위기 컷(있으면) 또는 객실 → 4장 객실·거실 → 5장 야경·전경·주변. 어두운 컷은 많아야 1장. 영상마다 "y"(0 위~1 아래)로 4:5 자를 위치를 정한다(주인공 시설이 가운데).

## 캡션 (숙찾남 구조 + 다꾸 금지어)
첫 줄 "~하는 방법이에요." 같은 한 줄 훅 → 2~3문장 소개(stays json 사실만) → ✓ 3줄(객실 번호·시설·거리처럼 확인한 사실) → "~할 때 저장해두세요." → 📌 현장 요금·운영 기간 한 줄 → "🔎숙소정보는 프로필링크에서 [NNN]번 검색해주세요!" → 해시태그 5개(지역+유형+추천).
숙찾남의 "댓글 남겨주시면 숙소 정보 메시지로 보내드릴게요"는 쓰지 않는다(@dagguu.trip 제한 이력: 댓글→DM 미끼). 체험단·모집·신청·무료·제공·숙박권·금액·팔로우·이벤트 금지, 지어낸 방문담 금지.
시온님이 올릴 때 "AI 정보" 표시를 켠다(AI 로 늘리고 움직인 영상).

## 2장부터 자막 상자 (2026-10-30 시온님이 룸투어 피드 화면 보여주며 "내일부터는 두번째 이미지부터 이런 느낌으로")
- 장면 json 2~5번에 "cap" 을 꼭 넣는다 → carousel_make.py 가 화면 아래쪽(아래에서 120px 위)에 반투명 밝은 회색 상자(얇은 검은 테두리, 가운데 정렬 2줄, 핵심 단어 **굵게**, 줄 끝 이모지 1개)를 얹고, @dagguu.trip 은 표지처럼 오른쪽 위 그대로(2026-10-30 시온님 "네모글씨는 이미지 하단으로, 내 태그는 원래대로 우측상단").
- 글 = 그 장면이 보여 주는 공간의 사실 한 가지를 쉬운 해요체 2줄(줄당 16자 안팎). 2~4장은 장면 설명(예: "통창 너머로 동해가 보이는\n**오션뷰 침실**에서 쉬어요 🛏️"), 5장은 {"red":"📌 숙소 정보가 궁금하다면","t":"프로필 링크에서 **[NNN]**번을\n검색해 주세요!"}.
- 참고 화면의 "무료로·역대급·찾았어요(방문담)·주말은 방이 금방 차요·댓글 남겨주시면 링크와 쿠폰 보내드릴게요"는 쓰지 않는다(@dagguu.trip 제한 이력: 무료·과장어·댓글→DM 미끼, 지어낸 경험). 오른쪽 위 "[광고]" 표시도 넣지 않는다(쿠팡 링크 없는 소개 글).
- 사진 카드뉴스(gen_insta.py, scripts/insta_queue.json)도 같은 "caps" 배열(2장부터 순서대로)로 같은 상자를 넣는다.

## MZ 스타일 스티커 (2026-10-30 시온님이 사진 꾸미기 앱 화면 보여주며 "이런 mz 스타일 스티커도 꾸며 줄 수 있어?")
- 사진 카드뉴스(gen_insta.py)에서 queue 항목에 "stickers": [[표지 스티커], [2장], [3장]…] 를 넣으면 scripts/cards/stickers.py 가 직접 그린 스티커를 얹는다: hand(손글씨+곱슬 화살표)·cloud(생각 구름)·bubble(말풍선)·tag(네모 라벨, 연두·노랑 바탕)·puffy(뭉게 글씨 "포근·풍덩")·burst(번쩍 말풍선)·star·spark·emoji. 폰트는 Google Fonts(Nanum Pen Script·Gaegu·Jua, OFL).
- 앱의 스티커 그림·폰트 파일은 가져오지 않는다. 글은 사진에 보이는 것·숙소 json 사실만, 짧은 반말/해요체. 무료·역대급·최저가·체험단·금액·댓글→DM 금지. 마지막 장엔 "🔎 프로필 링크에서 [NNN] 검색" 라벨.
