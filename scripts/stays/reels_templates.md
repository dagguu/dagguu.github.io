## 공통 규칙 (모든 틀)
- 길이 15~22초, 12~20컷. 컷 0.8~1.5초. 자막(=내레이션) 한 줄 2~5단어, 컷과 따로 넘어가게.
- 문장 5단: ① 훅 → ② 대표 시설 + 숫자 사실 1개 → ③ 객실·뷰 → ④ 밤/쉬는 장면 → ⑤ 마무리(계절·상황·저장 유도).
- 마지막 컷 = 첫 컷(반복 재생). 넓은 컷 ↔ 소품·디테일 클로즈업 번갈아.
- 사실은 stays json(lead·points·info·guide·photos cap)에 있는 것만. 숫자도 json 에 있는 것만(도보 5분, 입실 15:00 등).
- 쓰지 않는다: 다녀왔다·묵어봤다·만족했다·취소했어요 같은 경험담(AI 정보 표시를 켜도 거짓 후기), 가격·"N만원 아꼈어요", 무료·제공·숙박권·체험단, 최고·역대급·미쳤다·강력추천·가성비 최고, 댓글→DM·팔로우 요구, 유료 시설을 무료처럼(바비큐·온수 등은 "별도"·"미리 확인"), 숙소 사진에 없는 계절·날씨 입히기.
- 말투는 "발견·소개" 존댓말: "~더라고요" "~있어요" "~딱이에요" "~저장해두세요".
- 영상에 AI 인물(뒷모습)을 넣었으면 인스타 "AI 정보" 표시를 켠다(시온님이 올릴 때).

## 틀 1 · 계절 저장형 (스파·온수·불멍·통창 설경/단풍, 따뜻한 객실)
- 훅: "날씨 추워지기 시작하면 / 저장해둬야 할 곳이에요" · "단풍 지기 전에 / 여기 먼저 보세요"
- 흐름: 하늘·전경 → 따뜻한 물(스파·욕조) → 통창 밖 풍경 → 객실 → 밤 불빛
- 마무리: "올겨울 첫 여행은 / 여기부터 잡아두세요" (첫 컷으로 반복)

## 틀 2 · 의외 조합형 (콘셉트가 뚜렷한 숙소: 한옥·료칸·스위스풍·북유럽 등)
- 훅: "○○인데 / △△ 그대로예요" (예: "펜션인데 / 료칸 그대로예요") — json 콘셉트 말 그대로만
- 흐름: 콘셉트가 드러나는 외관 → 대표 공간 2곳 → 디테일 소품 → 밤
- 마무리: "멀리 안 가도 / △△ 기분 낼 수 있어요"

## 틀 3 · 공감 상황형 (카라반·글램핑·바베큐·편한 1박)

- 흐름: 해결되는 이유(문 열면 바로…) → 시설 → 객실 편의 → 밤
- 마무리: "그럴 땐 / 여기 한번 저장해두세요"

## 틀 4 · 대상 나열형 (가족·키즈·대가족·반려견: points 에 아이·가족·반려견이 있을 때)
- 훅: "아이랑 부모님까지 / 다 같이 갈 곳 찾다가 / 여기 보고 멈췄어요" (찾아보다 발견 = 사실)

- 마무리: "온 가족이 / 같이 가기 좋은 곳이에요"

## 틀 5 · 뷰 몰입형 (오션뷰·일출·산 능선·통창이 주인공)

- 마무리: "알람 없이 / ○○ 보고 일어나는 곳이에요"
