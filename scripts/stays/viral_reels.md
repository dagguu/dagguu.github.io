# 조회수 터진 숙소 릴스 분석 노트

시온님이 보내 주는 "조회수 터진 릴스 + 숙소"를 하나씩 분석해 쌓고, 여러 개에서 반복되는 점을 아래 "공통 패턴"에 모은다(2026-10-31 시온님 요청).
- 분석 방법: 화면 녹화 영상을 0.5초마다 잘라 격자로 보고(ffmpeg fps=2 tile), 장면이 바뀌는 시각(scene 0.2)으로 컷 수·컷 길이를 잰다.
- 볼 것: 길이·컷 수·컷당 초 / 첫 화면(제목·사진) / 장면 순서 / 색감·시간대 / 사람(비율·자세·옷) / 자막(글꼴·자리·끊는 길이) / 대본 흐름 / 소리(목소리·음악) / 만드는 방법(실제 촬영·AI 사진·AI 영상) / 댓글·좋아요 숫자와 그 이유.
- 숙소는 stay_list.json 에 "viral": true 로 넣는다 → pick_reel.py 가 확인된 신상 다음 순서로 고른다.
- 여기 정리는 참고용이다. 우리 릴스 규칙(reels_templates.md)에 넣는 건 시온님이 "적용해줘" 한 것만.
- 따라 하지 않는 것: 댓글→DM 정보 미끼("정보 궁금하면 댓글"), 지어낸 방문 경험담, 숙소에 없는 시설·활동, 확인 안 된 가격·신상·최상급.

## 공통 패턴 (지금까지 3개)
- 컷이 짧다: 0.9~1.4초. 한 장면을 1~2컷 쓰고 바로 다음 장면.
- 제목은 맨 처음 화면에 크게 2~3줄 → 바로 사라지거나(2·3번) 위에 계속 떠 있음(1번).
- 자막은 2~3단어씩 한 문장을 여러 컷에 나눠 이어 간다. 위쪽 3분의 1 자리가 많다(사람·풍경을 안 가림).
- 사람은 얼굴 없이 뒷모습·옆모습. 같은 옷을 입은 한 사람이 여러 장면에 이어 나와 "하루"처럼 보인다.
- 계절·시간을 바꿔 보여 준다: 노을·밤(2번), 겨울 눈 풍경(3번). 지금 계절보다 한발 앞선 장면이 잘 먹힌다.
- 해외 비교·의외 제목: "한국의 삿포로", "일본 료칸 온 기분", "이렇게 예뻐도 되나요?"
- 마지막은 "가보고 싶은 곳이에요 / 미리 저장하고 예약해 두세요"처럼 저장을 부르는 말.
- 댓글이 좋아요보다 훨씬 많은 영상은 거의 "댓글 남기면 정보" 미끼 때문 → 우리는 [NNN] 검색 안내로 대신.

## 1. 글램핑 (계정 hiroooong) — 2026-10-30
- 13.7초, 15컷, 컷당 약 0.9초(음악 박자에 맞춘 듯). 목소리 없이 음악만.
- 실제 폰 촬영. 맑은 한낮, 깊은 파란 하늘 + 초록 숲 + 주황 단풍 조금, 채도·선명도만 살짝.
- 제목: 영상 내내 맨 위. 1줄 손글씨체 질문 "글램핑장이 이렇게 예뻐도 되나요?" + 2줄 작은 정보 "부산, 대구에서 1시간⏰20만원대 신상글램핑⛺".
- 자막: 가운데 가는 흰 글씨, 그림자만. "산 중턱에 숨겨진 / 숲속 글램핑 / … / 두손 가볍게 가기 좋은 / 여기가 어디냐면" 으로 끊고 끝.
- 순서: 드론 전경 → 정자 → 침실 → 통창 숲뷰 → 사람(뒷모습) → 할로윈 꾸밈 → 포토존 → 불멍 → 산책로 → 계곡 → 바베큐 → 매점 → 표지판. 시설 나열형.
- 숫자: 좋아요 417 / 댓글 1,781 → "여기가 어디냐면" + 위치 묻는 댓글 유도.
- 우리에게 적용: 맑은 한낮 색감(2026-10-30 적용함).

## 2. 한옥 노천탕 독채 (계정 stay__list, AI 콘텐츠) — 2026-10-30
- 19.5초, 14컷, 컷당 약 1.4초. 음악 + (자막 대본).
- AI 로 만든 장면. 하루 흐름: 밤 노천탕 → 노을 마당(위에서) → 한낮 걷기 → 낮 탕 → 노을 탕 → 노을 보며 앉기 → 바베큐 → 밤 불멍 → 동그란 창 독서 → 노을 외관.
- 숙소만의 특징(동그란 달 창)을 5번 넘게 반복.
- 사람: 한국 남자 한 명, 14컷 중 9컷, 뒷모습·옆모습, 옷 두 벌(린넨 세트 → 니트)로 하루가 이어짐.
- 제목: 처음 0.8초 크게 "별 보며 즐기는 / 한옥 노천탕". 자막: 두꺼운 흰 고딕 + 그림자, 위쪽 3분의 1, 색 강조 없음.
- 대본: "별 보며 노천탕을 즐길 수 있는 한옥 독채 숙소인데요 / 오래된 한옥을 딱 한 팀만 쓰는데 / 마당 한가운데 돌 노천탕이 있어서 일본 료칸 온 기분이에요 / 해 질 녘 탕에 몸 담그면 단풍 든 산이 노을에 물들고 / 마당에서 바베큐 굽고 화로 앞에서 불멍하다 보면 시간 가는 줄 몰라요 / 단풍 다 지기 전에 꼭 한 번 가보고 싶은 곳이에요"

- 우리에게 적용: 하루 흐름(낮→노을→밤) (2026-10-31 적용함). 특징 반복·사람 비율·자막 위치·마지막 말은 보류.

## 3. 정선 모모의숲 (계정 staybro.kr, AI 콘텐츠) — 2026-10-31
- 17.1초, 14컷, 컷당 약 1.2초. 음악 + 자막.
- 만드는 법(추정): ① 실제 숙소 사진(외관·테라스·통창)을 AI 로 폭설 내린 겨울로 바꿈(건물 구조 그대로) ② 사진→영상(눈 내림·불꽃·커튼 흔들림, 카메라는 아주 조금) ③ 숙소 사진에 없는 장면은 통째로 AI 생성: 1인칭 털바지·어그 발끝 썰매, 눈밭 썰매장, 군고구마, 흰 패딩 여자가 눈길 걷는 뒷모습.

- 대본: "눈 질리게 보고 싶다면 이번 겨울엔 여기 가세요 / 해발 700m에 자리 잡아 눈이 내리면 온통 하얀 설국으로 변하는데요 / 숙소 주변에서 눈꽃 구경은 물론 바로 아래에서 얼음썰매까지 즐길 수 있어요 / 비행기 타고 가지 않아도 이런 겨울 풍경을 볼 수 있다니! / 게다가 숙소 가격도 10만원대라고 하니까 / 올겨울 눈여행 계획 중이라면 미리 저장하고 예약해두세요!"

- 우리에게 적용: 아직 없음("겨울 미리보기 릴스" 틀 제안함, 시온님 답 대기).
