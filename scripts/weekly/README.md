# 주간 감성숙소 모음 릴스 (매주 일요일, 2026-10-29 시온님)

시온님이 보여준 카페 모음 릴스(coffeegomi "추석에 가볼 만한 국내 카페 13곳") 형식: 9:16, 소리 없음(음악은 시온님이 인스타에서).
- 첫 2컷: 위쪽 가운데 얇은 흰 글씨 제목 "OO에 가볼 만한 감성숙소 N곳" + 작은 영어 "Stay trip in Korea".
- 그다음 숙소마다 1.2초 컷 2개, 위쪽 가운데 "1. 숙소이름 (지역)". 전체 12~20초.
- 그 계정의 영상·사진은 쓰지 않는다(형식만 참고). 숙소 영상은 다꾸가 만든 장면 영상(insta 브랜치 video/*/<slug>/clip_ai*·clip_p*.mp4)을 다시 쓴다 → kie 크레딧 0. 영상이 없는 숙소는 감성숙소 json 사진(p:N, 천천히 확대).

## 숙소 고르기
지난 일주일(월~토) 동안 올라온 감성숙소 매거진 글(scripts/stays/*.json date) + 그 주 릴스(scripts/reels_done.json) 숙소, 5~8곳. 계절에 맞는 숙소(10~3월: 온천·스파·노천탕·온수풀·따뜻한 객실)를 앞에. 같은 지역이 붙지 않게 섞는다.

## 컷 고르기
그 숙소에서 가장 눈에 띄는 장면 2개(대표 시설 + 객실·야경). 사람 컷은 전체에서 2~3개까지, 남자·커플 컷·뒤집힌 컷·글씨가 박힌 컷은 쓰지 않는다. 제목 컷(intro)은 전경·노을·드론처럼 넓은 장면.

## 캡션
첫 줄 한 줄 소개 → 번호 목록 "1. 이름 (지역) — 특징 한 줄 [NNN]" → "~할 때 꺼내 보게 저장해두세요." → "🔎숙소정보는 프로필링크에서 [번호]로 검색해주세요!" → 해시태그 5개. 체험단·모집·신청·무료·제공·숙박권·금액·팔로우·댓글→DM·과장어·지어낸 방문담 금지.

## 만들기
scripts/weekly/<일요일 날짜>.json(title, sub, intro, items[{slug,no,label,cuts}], caption) → 커밋·push → weekly-reel.yml(inputs date) → insta 브랜치 weekly/<날짜>/reel.mp4·cover.jpg, 상태 scripts/weekly_status.json.
