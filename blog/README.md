## 글 형식 (시온님이 준 예시 4개 기준)
- 제목: 숙소명 + 할인율 + "○○만원대" + 특가 이름 + 핵심 혜택 + "예약 꿀팁/총정리". **제목에 '여기어때' 금지** (여기어때 규정: 쓰면 그 글의 링크 실적 정산 제외·활동 정지 가능).
- 맨 위: 공정위 문구 (여기어때 권장) "여기어때 마케팅 파트너 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다." 마이리얼트립 링크가 있으면 같이 표기.
- "바쁜 분들을 위한 3줄 요약" → 예약 링크 → 지도 → 숙소 소개 → "예약 팁 1·2·3" 소제목(패키지별 가격·포함 내용 / 부대시설·주변 / 유의사항) → 체크 포인트 정리 → 예약 링크 한 번 더.
- 모바일용 짧은 줄 + 빈 줄. "~해요" 말투. 이모지는 👉 정도.
- 가격 차이·1인당 금액 같은 계산, 타사 가격 비교(여기어때 권장: 가격 비교로 신뢰 높이기). 숫자는 확인한 것만.
- 안 가본 숙소를 다녀온 것처럼 쓰지 않는다. 사진 자리는 [사진 N : 설명] 으로 표시.
- 링크 자리는 [여기어때 링크: 숙소명/URL], [쿠폰팩 링크], [마이리얼트립 링크] 로 표시. 링크는 '예약 유도 문구'에 넣고, 숙소 링크는 썸네일이 뜨게 그대로 붙인다.
- 맨 끝(마지막 여기어때 예약 링크 뒤, 태그 앞)에 시온님 사이트 한 줄 + 주소를 **항상** 넣는다(2026-10-15 시온님 요청): "더 많은 숙소 특가와 체험단 소식은 / 다꾸 체험단 모음에서 확인하세요 / https://www.dagguu.com". 썸네일 카드는 여기어때 링크에만, 사이트는 "더 싸게" 같은 가격 비교 문구 없이 소개만.
- SEO 기준 (2026-10-15 시온님 요청):
  - 대표 키워드 = 숙소명. 제목 맨 앞 1회, 본문 5~8회(링크 문구 포함).
  - 지역 키워드 = "지역+숙소유형"(경주 호텔, 속초 리조트, 속초 오션뷰 숙소 등) 1~2개. 제목 뒷부분 1회, 본문 3~4회, 문장 속에 자연스럽게.
  - 상업 단어: "특가"+"할인" 본문 합쳐 8회 이하(링크 버튼 문구는 "○○ 오픈런 보러가기"처럼 특가 빼기). "무료·최저가·강추·강력추천·파격·압도적·공짜"는 제목·본문에 쓰지 않는다("추가 요금 없이", "포함"으로). 의료·시술·대출·보험·렌터카·부동산 단어도 피한다.
  - 본문 1,500자 이상(공백 제외), 사진 자리 8개 이상(가격 비교 캡처 자리 1개 포함).
  - 키워드를 억지로 반복하지 않는다(어색하면 횟수보다 자연스러움 우선).
- 태그 10개 안팎(숙소명·지역·숙소 유형·여행 테마).
