# 추천 모음 페이지 (p/) 만드는 규칙

2026-10-20 시온님 요청으로 매일 1개씩 만든다. 검색(네이버·구글) 유입과 파워링크 도착 페이지용.
대량 생성 스팸으로 보이지 않게, 페이지마다 그 주제에 맞는 글을 새로 쓴다. 기준을 못 넘는 날은 만들지 않는다.

## 주제 고르기
- 다꾸 분야(육아·생활·가전/가구·반려동물·여행 준비물·선물)와 이어지는 "제품 + 추천/선물/고르는 법" 주제.
- 네이버 키워드 도구(datalab.yml 수동 실행, inputs[hints]=쉼표 5개 이내씩) 결과 scripts/kw_extra.json 에서
  핵심 키워드 + 연관 키워드 월간 검색 합이 3,000 이상.
- 이미 있는 페이지(scripts/picks_*.json 의 keywords·h1)와 겹치지 않기.
- 빼는 주제: '쿠팡' 들어간 키워드, 다른 회사·브랜드 이름 키워드, 의약품·의료기기·건강기능식품 효능이 핵심인 주제(영양제·유산균 효과 등), 성인용품, 주류·담배, 정보만 찾는 키워드(계산기·뜻·방법만).
- 후보 예(검색 수 확인 후): 아기띠 추천, 분유포트 추천, 신생아 가습기 추천, 옆잠베개, 집들이선물 추천, 백일·돌선물, 아기 욕조, 유모차, 카시트, 아기 체온계(효능 문구 없이), 겨울 캠핑 준비물, 강아지 자동급식기, 고양이 정수기, 전기요·온수매트, 음식물처리기 추천.

## 상품
- scripts/match_queries.json 에 주제별 검색어(최대 30)를 push → coupang-match.yml 이 scripts/match_results.json 에 결과(pid·name·price·img·url(파트너스 링크)·rocket).
- 결과에서 주제에 정확히 맞는 상품만 12~18개. 엉뚱한 상품(검색어와 다른 물건)은 뺀다. 같은 상품 색상만 다른 건 하나만.
- 칸(section) 3~4개: 예산별 또는 종류별. 칸 이름과 가격이 맞아야 한다(예: "3만원 이하" 칸에 3만원 넘는 상품 금지).
- item: {name, pid, price(정수), img, url, rocket, kind(짧은 분류 이름)} — match_results 값 그대로.

## 글
- 파일: scripts/picks_<slug_밑줄>.json (slug 는 영문 소문자-하이픈, 예: baby-carrier → picks_baby_carrier.json)
- 필드: slug, date(오늘), title(60자 안, 끝에 " | 다꾸체험단"), desc(120자 안), h1[두 줄], lead(2문장),
  tipsTitle(선택), tips[[이모지, 굵은 말, 설명]] 5~6개, guide[{h, p[2~3문단]}] 2개, sections[{t, d, items}],
  faq[[질문, 답]] 3개(가격 질문은 자동으로 붙음), camp{cat(baby/life/elec/pet/stay/beauty/health/etc), q(관련 단어 정규식, 선택), h, p, more}, keywords[파워링크용 키워드].
- 쉬운 존댓말(~해요). 일반적으로 알려진 고르는 기준만 쓰고, 상품별 성능·순위·"1위/최고/최저가/강력추천/무료"·효능·의학적 표현은 쓰지 않는다. 숫자(용량·소음·인증)는 상품명에 있는 것만.
- 다른 페이지 문장을 복사하지 않는다. tips·guide·faq 를 주제마다 새로 쓴다.

## 마무리
- python3 scripts/gen_share.py (gen_picks.py 도 같이 돌고 sitemap·p/list.json 갱신) → ls s | wc -l 확인 → 커밋·push.
- 알림: 페이지 제목·주소, 고른 키워드와 월간 검색 수, 파워링크 소재 1안(제목 15자 이내·설명 45자 이내, '쿠팡'·최저가·1위 금지).
